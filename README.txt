# RankingRock

Web interactiva de torneo del rock nacional argentino.

## Cómo funciona
- Cada partida elige 16 artistas de una lista grande.
- Se juegan octavos, cuartos, semifinales y final.
- El usuario elige quién avanza en cada cruce.
- El historial se guarda en el navegador.
- Los artistas que aparecieron menos veces tienen mayor probabilidad de ser elegidos en próximas partidas.
- Hay bandas y solistas.

## Publicarla gratis
La forma más sencilla para tener un enlace público es subir `index.html`, `style.css` y `script.js` a un repositorio de GitHub y activar GitHub Pages.
La página puede ser pública y cualquier persona con el enlace podrá jugar.

También se puede conectar luego un dominio propio.
